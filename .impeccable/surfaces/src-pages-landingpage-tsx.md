Scope: public landing page (Persuade) and the authenticated app shell + dashboard (Operate), one shared world. Visitors: Space Apps judges with minutes per entry; students on classroom laptops.

## Direction contract

THESIS: ORBIT-X is a mission design program, presented with the discipline of the 1975 NASA Graphics Standards Manual: a strict modular grid, grotesque type, NASA red used as a committed field, technical-drawing precision. It refuses the category default of a near-black page with glowing neon panels and glass.

OWN-WORLD: Paper-white ground (#F5F6F7), carbon ink (#121316), NASA red (#FC3D21 for fields, #D2301B for text-bearing controls), agency blue (#0B3D91) for links and data series. Archivo for all type (heavy, tight display; regular for UI), Geist Mono only for measurements. Square-cut corners (2–4px), 1px ink hairline rules, no glows, no glass, no gradients in chrome. A carbon-black navigation rail. 3D views sit in black "space windows".

STORY: A judge understands in one viewport that this is a complete mission-design game with real physics, sees the live launch telemetry proving it, and starts a mission (or a no-sign-up demo) in one click.

FIRST VIEWPORT: Landing: left two-thirds, a massive tight headline set flush-left on the grid, short deck, red primary action "Start a mission" plus a no-sign-up row; right third, a black space window with the photographic Earth and a live ascent-profile plot computed from the game's own trajectory model. A full-width flight-plan rule beneath with the eight mission phases ticked like a technical drawing.

FORM: Pinned by the brief (NASA agency aesthetic), translated through the Graphics Standards Manual. Position 1 on the ordered list. seed: none (unavailable)

Signature move: the flight-plan rule, a horizontal ruled timeline with tick marks and phase labels, reused on landing, dashboard and launch.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
